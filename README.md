# my-java-app2

[![CI](https://github.com/bazoocaze/my-java-app2/actions/workflows/ci.yml/badge.svg)](https://github.com/bazoocaze/my-java-app2/actions/workflows/ci.yml)

Simple Spring Boot REST API with Java 21.

## Quick Start

```bash
./local/build.sh      # build JAR
./local/run.sh        # run locally on port 8080
```

## Endpoints

- `GET /hello` — returns "Hello from my-java-app2!"
- `GET /actuator/health` — health check
